## Как читать

- **Скорость убийств 18/мин** — измерена headless-ботом (учитываются и убийства «игроков»-NPC). Меняется переменной `KILLS_PER_MIN=… npm run balance`.
- **Доход на убийство** = пепел за убийство (`loot.ash`, растёт с уровнем и глубиной) + продажа выпавших вещей (`items.sellRatio`).
- **Покупка** = `price × shop.buyMarkup[редкость]`. Клеймёное в магазине не продаётся — только Предвестник.
- **Кузнец**: цена уровня `(smith.baseCost + price × costPerPrice) × costGrowth^уровень`; шансы `smith.success`; с `breakFrom` неудача ещё и снижает уровень. Таблица считает ожидание Монте-Карло с учётом этого.
