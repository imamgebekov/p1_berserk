# Берсерк

Тёмный пиксельный экшен-RPG для телефона (вертикально, большие пальцы). Всё рисуется кодом и синтезируется, внешних картинок, шрифтов и звуков нет. Зависимостей в игре нет; `vite` нужен только как dev-сервер и сборщик.

## Запуск

```bash
npm install
npm run dev          # сервер для разработки, доступен по сети
```

Vite напечатает строку вида `Network: http://192.168.1.23:5174/`. Откройте этот адрес в Safari на iPhone (телефон и компьютер в одной Wi-Fi сети). Если не открывается — проверьте, что брандмауэр компьютера пускает порт 5174.

Совет: в Safari «Поделиться → На экран „Домой“» откроет игру без адресной строки.

Продакшн-сборка: `npm run build`, потом `npm run preview` (тоже по сети).

## Тесты

```bash
npm test             # предметы, экономика, прогресс, бой + headless: тысячи кадров с эмуляцией ввода (~30 с)
npm run icons        # перерисовать иконки в public/
npm run balance      # таблица баланса экономики (см. docs/balance.md)
npm run test:browser # Chromium: мобильный вьюпорт, касания, размеры кнопок; прогресс и сохранение; пауза, настройки, офлайн
npm run test:all
```

`SEED=5 FRAMES=50000 npm test` — другой прогон. Браузерный тест нужен Playwright (если его нет, тест пропускается).

## Предметы

Слоты: оружие, голова, тело, плащ, амулет, кольцо. Редкость: обычный, редкий, проклятый (сильно, но со штрафом), клеймёный.
Статы: урон, броня, здоровье, скорость, шанс крита, скорость набора Клейма.
Дроп зависит от типа врага (`config.js → loot.drops`), глубины (расстояние от города) и уровня; лучшее падает с Предвестника.
Пока открыта «Сумка», игра на паузе. Сумка полна — новая вещь сразу продаётся за пепел.
Распечатка таблицы дропа: `node test/items.mjs`.

## Внешний вид героя

Герой рисуется слоями: плащ → ноги → тело/броня → амулет → голова/шлем → оружие → рука с кольцом. Цвета слоя — `pal` предмета (`data/items.js`), форма — `data/looks.js`.
У каждого оружия свой силуэт (тесак, дугой палаш, плита, двуручник, зубчатый, топор) и длина клинка: чем длиннее, тем больше дальность удара (`config.js → player.reachPerLen`).
Эффекты редких: искры (костяной клинок), тлеющий край (Тлеющий клинок), фиолетовая дымка (проклятые), красный след и угольки (клеймёные).
При `prefers-reduced-motion` частицы и мерцание отключаются.

## Город и экономика

У костра стоят **торговец** (слева) и **кузнец** (справа, у наковальни). Подойдите — в HUD появится кнопка «Торговец» / «Кузнец».
Враги в город не заходят; пока окно открыто, игра на паузе.
Торговец: 8 вещей (3 дешёвых обычных всегда), обновляется после каждого Предвестника; клеймёное не продаётся. Цена покупки — `price × наценка редкости`, продажа — 30% цены; «Продать весь хлам» одним тапом.
Кузнец: оружие до +10; с +5 шанс успеха падает, при неудаче пепел сгорает, с +7 неудача ещё и снижает уровень. Оружие не ломается.
Все числа — в `src/config.js` (`loot.ash`, `shop`, `smith`, `items.sellRatio`); таблица ожиданий — `docs/balance.md`.

## Навыки, задания, сохранение

**Навыки** (вкладка «Навыки», кнопка внизу пульта): 8 узлов в трёх ветках — «Меч» (Сокрушение → Длинная цепь → Меткость),
«Клеймо» (Жажда → Тлеющее Клеймо), «Выживание» (Живучесть → Целебный огонь → Лёгкая поступь). 1 очко за уровень и за часть заданий.
Эффекты по рангам — `config.js → skills.effects`. Сброс стоит пепла (`skills.respecBase/respecPerLevel`).

**Задания** — у Хранителя костра (у огня; «!» над головой — есть задания, «?» — можно сдать). Одновременно до 3 (`quests.maxActive`).
Список — `src/data/quests.js` (убей 10 рогачей, пережди затмение, закалка и др.), прогресс показывается в HUD.

**Сохранение** — localStorage, ключ `berserk.save`, формат с версией (`save.js → VERSION`). Автосохранение каждые 10 с,
по событиям (уровень, Предвестник, покупка, задание) и при сворачивании страницы. Данные при загрузке очищаются и проверяются;
при повреждении или сохранении из будущей версии исходник откладывается в `berserk.save.bak`, начинается новая игра.
Чтобы поменять формат: поднять `VERSION` и добавить `MIGRATIONS[старая версия] = данные => новыеДанные` в `save.js`.
Сброс: вкладка «Герой» → «Сбросить прогресс» (два тапа) или «Начать заново» на экране входа.

## Телефон: пиксели, пауза, настройки, установка

**Чёткие пиксели.** Масштаб всегда целый (4×, 5× …), поэтому пиксели одинаковые. Ширина мира подбирается под экран (на iPhone около 165–195 логических px).
**Пауза.** Кнопка «Пауза» справа сверху; игра сама встаёт на паузу при сворачивании Safari и при повороте телефона в горизонталь (там показывается «Поверните телефон»). После возврата игра ждёт нажатия «Продолжить».
**Настройки** (на паузе и на экране входа): громкость, звук, режим левши (зеркальная раскладка кнопок), «меньше движения» (авто следует настройке iPhone). Хранятся отдельно от прогресса: `berserk.settings`, переживают сброс.
**Установка на экран «Домой»:** в Safari «Поделиться → На экран „Домой“» — игра откроется без адресной строки, с иконкой.
**Офлайн** работает через service worker и только по **HTTPS** или `localhost` (требование iOS). По `http://192.168…` в локальной сети офлайна не будет, зато всё остальное работает. Чтобы играть без сети на телефоне, разместите содержимое `dist/` (команда `npm run build`) на любом HTTPS-хостинге (GitHub Pages, Netlify и т. п.).

## Бой

**Перекат** (кнопка в средней колонке пульта, клавиша `V`): рывок вперёд на ~40 px, неуязвимость на время переката и немного после, отменяет замах, перезарядка 0,9 с (навык «Лёгкая поступь» сокращает). Если удар или стрела пришли во время переката — «Уклон!» и +12 Клейма (один раз за перекат). Числа — `config.js → roll`.
**Лучник** (с 3 уровня): держит дистанцию 62–104 px, натягивает лук (предупреждение), стрела летит ~115 px/с; её можно перепрыгнуть или проскочить перекатом.
**Прыгун** (с 4 уровня): приседает (предупреждение «!») и бросается по дуге на ~90 px; урон при пролёте и при приземлении; после — пауза, когда он уязвим. Состав обычных врагов — `config.js → spawn.pool`.
**Предвестник**: на половине здоровья вторая фаза — быстрее, ревёт (пауза), призывает двух бесов, а к удару по земле добавляется **взмах крылом** по линии ±74 px (красная полоса на земле): спасает прыжок или перекат. Числа — `config.js → bossPhase`; на шкале здоровья есть отметка фазы.

## Публикация на телефон по ссылке (GitHub Pages)

Рабочий процесс `.github/workflows/pages.yml` при каждом пуше в `main` прогоняет тесты, собирает игру и публикует её на GitHub Pages.
Один раз включите: **Settings → Pages → Build and deployment → Source: «GitHub Actions»**. Дальше всё автоматически.
Игра откроется по адресу `https://<пользователь>.github.io/<репозиторий>/` — это HTTPS, поэтому на телефоне работают офлайн-режим и установка на экран «Домой».
Хостинги Netlify и Cloudflare Pages тоже подойдут: команда сборки `npm run build`, папка `dist`, `NODE_VERSION=22` (файл `public/_headers` настраивает кэш).

## 3D-прототип (`/3d/`)

Отдельная страница рядом с 2D-игрой: `http://<адрес>/3d/` (с главного экрана 2D есть ссылка «3D-прототип →»).
Вертикальный экран, плавающий джойстик слева, «Удар» (держать) и «Перекат» справа.
Графика — Three.js (версия закреплена), модели из кубиков, внутреннее разрешение занижено и растянуто без сглаживания (пиксельный стиль).

- Все числа в `3d/src/config3d.js`; логика без графики в `3d/src/sim.js` (тест: `node test/sim3d.mjs`).
- Кнопка ⚙ открывает ползунки (камера, размер «пикселя», скорость, дальность удара, число врагов…). Значения сохраняются в браузере; «Скопировать» отдаёт изменённое одной строкой.
- Браузерный тест с WebGL и скриншотами: `node test/browser3d.mjs` (картинки в `test/out`).

### Деревня в 3D

В `3d/src/config3d.js`, раздел `map.buildings`, дома задаются списком: центр `x, z`, размеры `w, d`, сторона двери `door` (`n`/`s`/`e`/`w`). Добавьте строку — появится новый дом.
Стены не пускают, в дверь проходит и рогач; когда герой внутри, крыша тает, а стены опускаются (вид как в Project Zomboid). Враги заходят за героем через дверь и не бьют сквозь стену.
Камера повёрнута на `view.camYaw` градусов (по умолчанию 38, «изометрия»), джойстик поворачивается вместе с ней; угол есть среди ползунков.
Тест карты: `node test/map3d.mjs`.

Вещи и сумка (3D)
- Каталог `3d/src/data/items.js`: 451 вещь (оружие 119, броня 140, кольца и амулеты 56, расходники 37, материалы 30, диковины и записки 65, ключи 4). Оружие и броня собираются из типов × материалов, остальное написано руками. Названия и тексты авторские.
- Добыча `3d/src/data/loot.js`: 18 видов контейнеров (ящик, бочка, мешок, сундуки разной крепости, запертый, шкатулка, шкаф, оружейная стойка, могила, алтарь, тайник, телега и др.) с таблицами добычи. Чем дальше от костра, чем лучше контейнер и чем больше у героя удачи, тем реже и лучше вещи. Свечение над контейнером показывает редкость лучшей вещи внутри.
- Запертые сундуки открываются ключом нужного уровня (тратится самый слабый подходящий). С монстров выпадают вещи на землю (рогачи роняют лучше).
- Кнопка 🎒: надетое (оружие, голова, тело, плащ, ноги, кольцо, амулет), вкладки, сравнение с надетым и стрелка ▲, «Надеть / Использовать / Продать / Выбросить». Сохранение в браузере (`berserk3d.save`), в окне есть «Сбросить прогресс».
- Тесты: `node test/items3d.mjs`, `node test/inv3d.mjs`.

Ещё в деревне: двери открываются сами, когда рядом кто-то есть (герой или враг), и закрываются за ним.
Слух врагов (`enemies.hear`): стоящего героя слышат с 10 м, бегущего с 17, дерущегося с 25, в доме тише. Не услышавший бредёт к герою вполсилы; получив удар, слышит всегда.

Мир (3D)
- 17 зданий семи типов (`kind`: house, shop, smithy, tavern, chapel, barracks, warehouse, hut): у каждого своя обстановка (`3d/src/furniture.js`) и набор контейнеров. Области: кладбище с могилами-контейнерами и склепом, ферма с полем и стогами, рынок с прилавками и колодцем, руины, лагерь с палатками. Дороги от костра к дверям, фонари, заборы. Деревья и камни не растут на дорогах, в домах и областях.
- Всего 73 контейнера 18 видов. Тест `node test/world3d.mjs` проверяет, что ничего не наложено, дверь ни одного дома не загорожена и до каждого контейнера можно дойти пешком (поиск пути по сетке).
- Торговец в лавке: кнопка «Торговать» появляется рядом. Покупка (цена вещи ×2,2) и продажа (×0,5), «продать весь хлам» одной кнопкой, витрина обновляется раз в 5 минут. Продавать из сумки можно только у торговца. Тест `node test/shop3d.mjs`.
- Всё настраивается в `3d/src/config3d.js`: `map.buildings`, `map.spots`, `map.zones`, `shop`.

Бой и кузнец (3D)
- Четыре вида врагов: бес, рогач, гончая (быстрая, у руин и лагеря), упырь (у кладбища). Область определяет, кто там водится (`enemies.regions`). Чем дальше от костра, тем враги крепче и злее (`depthHp`, `depthDmg`).
- Костёр лечит в радиусе 5 м, если последние 3 секунды не было боя (`player.fire`).
- Кузнец (здание `smithy`): кнопка «Кузнец» рядом с ним. Улучшение вещи до +5 за пепел, каждый уровень даёт +10% к урону, броне, здоровью, криту и вампиризму (`smith`). Уровень остаётся при снятии и надевании и сохраняется.
- Баланс проверяет бот: `node test/balance3d.mjs` печатает таблицу (смертность, убийства, урон на убийство для четырёх уровней экипировки в трёх местах мира) и следит за «лестницей силы».

Уровни, навыки, места, отряд (3D)
- Опыт за убийства, уровни до 30 (+4 здоровья, +0,4 урона, +1 очко навыка за уровень). Древо навыков: три ветки (Ярость, Стойкость, Скиталец) по пять навыков, каждый следующий открывается вложением очков в ветку; сброс за пепел (кнопка ✦). `3d/src/data/skills3d.js`.
- Места (`map.places`): города и посёлки безопасны (враги не рождаются, услышавшие теряют след), опасные зоны (Погост, Сухие Поля, Руины Скорби, Лагерь Ржавых, опасность 1–3) дают более крепких и многочисленных врагов, лучшую добычу и опыт. При входе показывается название. Миникарта в углу и большая карта по касанию, с «туманом войны» (открывается по мере хождения, сохраняется).
- Отряд: капитан Заставы нанимает стражников, ратников и ветеранов. Бойцов идут за героем, бьют врагов (опыт и добыча идут герою), врагам они тоже цели, гибнут навсегда, лечатся вне боя, у костра быстрее. Мест в отряде 1, +1 за каждые 8 уровней (до 4). `squad` в конфиге.
- Тесты: `node test/progress3d.mjs`, `test/places3d.mjs`, `test/squad3d.mjs`.

Оружие и эффекты (3D)
- Умения типов: у каждого из 17 типов своё поведение (кинжал бьёт в спину ×2,2, копьё колет узко и далеко, молот задевает всех вокруг цели и оглушает, цеп бьёт дважды, коса и двуручник рубят почти по кругу, булава оглушает, нож и серп вызывают кровотечение, клевец и рапира крит сильнее). `3d/src/data/weapons3d.js`.
- Свойства: огонь, холод, яд (стакается до 5), гроза (молния на соседа), рваная рана, добивание, жатва (лечит за убийство), эхо, раскат (крит взрывается), жнец, раскол, оплот. Есть у костяного, чёрного и кровавого оружия, у 12 зачарованных клинков и у 16 уникальных.

Версия 2.3, шаг E1: фильтр ASCII (3D)
- **Вид «ASCII»** (по мотивам Moonlit Cave): кадр из символов. Включается в ⚙ кнопкой «🔤 Вид», выбор хранится в настройках; для ссылок и тестов — `?ascii`. По умолчанию выключен, обычный вид не менялся.
- **Как устроено** (`ascii3d.js`):
  - сцена рисуется в маленькую текстуру, 2×2 текселя на клетку (с версии 2.4 — 6×10 CSS-точек);
  - проход на весь экран заменяет клетку символом: яркость выбирает плотность, оттенок — набор (зелень — штрихи травы, синее — волны `~`, остальное — `` .`',:;+=*%#@``);
  - по перепаду яркости внутри клетки рисуется штрих контура `| / - \`, поэтому дома, берега и фигуры читаются;
  - темнее порога — пусто (чёрный фон), яркие клетки светятся, редкие клетки мерцают (не при «Уменьшить движение»);
  - цвет символа — цвет клетки.
- **Атлас символов** строится при запуске из системного моноширинного шрифта. Плотность каждого символа меряется по факту, внешних файлов нет.
- **Чёткие метки боя** поверх символов: полосы здоровья, круги замаха, телеграфы боссов и стрелков, круги града, дуга удара, кольцо заряда.
- **Свет над героем:** в ASCII над героем мягкий свет, чтобы он выделялся пятном плотных символов.
- **Холст в полный размер:** в ASCII холст рисуется в полный CSS-размер, «Размер пикселя» не действует. Подсказка о малом числе кадров советует выключить ASCII.
- Числа — `view.ascii` в `config3d.js`.
- Кадры (версия 2.3): WebKit — 61 кадр/с в обоих видах. В Chromium без видеокарты (программная графика) ASCII медленнее: 23 против 55.
- Тесты:
  - `test/ascii3d.mjs` — наборы, ступени, набор по цвету, штрихи, совпадение формул JS и шейдера, настройка;
  - в браузерном тесте на Маке — включение и выключение, размер холста, тёмный фон, чёткая полоса здоровья, кадр `test/out/3d-desk-ascii.png`.
